# Fehlzeiten-Tracker

Lokale Anwendung für Lehrkräfte: unentschuldigte Fehlzeiten wöchentlich erfassen, Verspätungen und Fehlstunden automatisch in Fehltage umrechnen und rechtzeitig vor einer fälligen Schulversäumnisanzeige warnen.

- Läuft ausschließlich lokal, ohne Server und ohne Cloud
- Datensparsam: nur Vornamen, Klasse, Fehlzeiten
- Verschlüsselte lokale Datendatei

Status: in Planung. Die Anforderungen stehen in [docs/anforderung.md](docs/anforderung.md).

> Dieses Repository enthält nur Code und Dokumentation, niemals echte Schülerdaten.
